➕ Setup Real AI Brain (Cloudflare) — Mobile Steps

Step 1. Cloudflare Dashboard → Workers & Pages → Create a new Worker named zara-ai-chat.

Step 2. Connect GitHub repository manzoor4670/zara-ai-companion-, branch main. Keep this as a separate Worker from the existing Dress Try-On Worker.

Step 3. In Build settings use the command below, then deploy:

npx wrangler deploy --config wrangler.chat.toml

Step 4. In the NEW Worker → Settings → Variables and Secrets, add a secret named GEMINI_API_KEY using your own key. Never paste the key in this public website or GitHub.

Step 5. Copy the new Worker's real https://...workers.dev URL into the field above, tap Check AI Connection, then Save Training. Reopen Zara Chat and send a test message.

➕ OpenRouter Free AI Fallback (optional)

If Gemini says your API location is unsupported, use OpenRouter free models as a fallback for Zara. Normal, Romantic, and adult flirty (non-explicit) modes remain available; each model has its own content policy.

Step 1: Open OpenRouter ↗, create an account, then create your API key at API Keys ↗.

Step 2: Cloudflare → Workers & Pages → zara-ai-chat → Settings → Variables and Secrets → Add.

Step 3: Add key name OPENROUTER_API_KEY as a Secret, enter the private OpenRouter API key, then deploy the variable.

Step 4: Reopen Zara Chat and send a new message. The Worker will try Gemini, then use openrouter/free if Gemini rejects the request. The free model may change per request, and free rate limits apply.

Never paste API keys here, in GitHub or Chat. Public Workers should have authentication and rate limiting before wider use. This fallback provides text replies, not generated dress images.

Important: Creating or deploying Cloudflare Worker and adding the Gemini key are not automatic. The AI chat stays in Demo Mode until setup succeeds. Public deployments require authentication and rate limiting to protect usage quotas.
