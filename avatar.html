📱 Mobile Steps: IDM-VTON
  1. Upload Zara full-body image above.
  2. Add a clear dress photo and tap Choose in My Dress Gallery.
  3. Tap Save Zara Image, then Save Selected Dress.
  4. Tap IDM-VTON (Hugging Face). On its page, upload Zara as Human Image and dress as Garment Image.
  5. Use the demo Try-On button. Download the output when ready.
  6. Return to Zara Studio and choose Upload generated result in the Import section.
  7. Compare the two faces, then save the result if you like it.

This is a manual workflow. Face Lock here does not control the external IDM-VTON demo. Do not upload private photos without permission.
